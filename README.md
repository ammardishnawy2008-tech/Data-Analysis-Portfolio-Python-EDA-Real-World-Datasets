# 📊 Data Analysis Portfolio | Python & EDA

Welcome to my data analysis portfolio.  
This repository contains a collection of hands-on projects that demonstrate my skills in data cleaning, exploratory data analysis (EDA), and data visualization using Python.

The projects are based on real-world datasets and follow a structured analytical workflow — from raw data to clear insights.

## 🧠 Skills & Tools

- Python

- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Data Visualization (Matplotlib, Seaborn)
- Working with Real-World Datasets
